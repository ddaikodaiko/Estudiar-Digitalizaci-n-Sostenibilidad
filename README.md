# Tests de repaso

Tests tipo test de Digitalización y Sostenibilidad (preguntas de los Kahoots de clase), con las preguntas y respuestas mezcladas en cada repetición.

- **Nota proyectada:** probabilidad de acierto de cada pregunta según tus intentos (los recientes pesan más) → 10 × media del banco.
- **Horas hasta el 10:** ajuste exponencial del error proyectado frente al tiempo de estudio acumulado.
- El progreso se guarda en el navegador (localStorage).
