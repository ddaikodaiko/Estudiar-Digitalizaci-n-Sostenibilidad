# Tests de repaso

Tests tipo test de Digitalización y Sostenibilidad (preguntas de los Kahoots de clase), con las preguntas y respuestas mezcladas en cada repetición.

- **Nota en el examen:** simula 4.000 exámenes de 30 preguntas de los 3 temas mezclados con la probabilidad de acierto de cada pregunta (intentos recientes pesan más) → nota media, rango y probabilidad de sacar 10.
- **Horas hasta el 10:** ajuste exponencial del error frente al tiempo de estudio, hasta que sacar 30/30 sea más probable que no.
- El progreso se guarda en el navegador (localStorage).
